# v0.14.4

- 无人值守检测到玩家手动操作后保持开启，只让出当前操作窗口，在新的可操作窗口自动恢复，不补发同一窗口的操作。
- 玩家主动关闭无人值守开关后保持关闭，不会自动开启。
- 自动下一局与无人值守解绑：自动下一局开启且助手服务运行时，即使无人值守关闭、玩家手动打牌，也会执行已支持结算界面的自动续局。
- 游戏内菜单、悬浮窗与设置页同步更新开关说明。模型自检不续局，手动取消匹配仍受尊重。
- 包含 v0.14.3 的猫头提示、重复牌黄色提示修复与登录 Dispose Hook 闪退风险修复。

本地验证：31项JVM回归、28项自动续局、63项自动操作检查通过；主代码及Android测试编译通过。实际设备登录与续局体验仍需更多验证。

安装提示：v0.14.2及更早发行版可能使用临时CI签名；如提示签名不一致，请备份模块配置后卸载旧模块再安装，不要卸载雀魂游戏。v0.14.3起使用固定签名。
