# v0.14.22

- 修正显示模式语义：启动前在应用内二选一，助手启动时固定读取所选模式；本次运行只创建这一套界面。
- 选系统悬浮窗时不创建游戏内控制或提示层；选游戏内 Hook 时不创建任何系统悬浮窗口。
- 删除显示租约、交接确认和自动回退机制。悬浮窗缺少权限或创建失败时保持原选择并记录错误，不自动启用 Hook。
- 游戏进程异步读取模式，确认前不绘制；查询失败保持未知或已知状态，不默认切换 Hook，避免阻塞游戏主线程。
- 运行期间锁定选择按钮。停止助手并重新启动游戏后，再使用新选择；原有界面、遥测误判与导出修复保持。

本地验证：单模式检查55项、回执链路58项、既有纯逻辑41项通过；Android设备94项控制器检查通过。全ABI安装包由CI完成构建与模型/JNI检查后发布。
