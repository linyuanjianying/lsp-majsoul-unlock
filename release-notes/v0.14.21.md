# v0.14.21

- 修复坐标采集信息被误判为操作失败：`hand_geometry`、`button_coords` 与 `hand_coords` 统一走遥测路径，不再清空待执行命令或触发等待同步；无 ID 的未知回执不再作为具体命令的拒绝。
- 操作日志增加完整回执 ID 与阶段，修正原因字段截断；真正重复的拒绝按有界时间窗口汇总计数。
- 日志导出与应用更新使用独立 FileProvider 组件，分享前实际读回 ZIP 校验；补齐分享 URI 授权、分享目标查询、失败提示及下载目录兜底。
- 加强系统悬浮窗与游戏内绘制的交接：游戏内表面先隐藏并确认，再显示系统窗；返回内绘制前先移除系统窗，丢弃旧代次回复。
- 保持原有界面，本次不包含美化预览改动。

本地验证：58 项回执链路检查、41 项既有纯逻辑检查、31 项显示互斥检查通过；Android 设备 94 项控制器检查及 Provider/ZIP 读取检查通过。报错者设备上的实际对局仍需复测。正式 APK 由 CI 执行全 ABI 构建、签名和 Android 模型/JNI 检查后发布。

安装更新后请彻底退出并重启游戏，以加载新 Hook 代码。
