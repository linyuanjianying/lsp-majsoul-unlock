# v0.14.3

- 出牌与操作提示替换为猫头样式，保留操作名、概率和金色/蓝色推荐等级。
- 修复推荐牌为对子或刻子时，最高推荐提示被跳过的问题；赤五与普通五分别匹配。
- 保留原始推荐排名，避免过滤后提示颜色错位。
- 修复 Hook 提示坐标来源尺寸变化被去重忽略，以及更新异常后未重试的问题。
- 移除与两份登录后原生崩溃记录相关的 WebSocket.Dispose 内联 Hook，保留 Close 清理，降低登录阶段闪退风险。尚需更多真实登录与断线重连验证。
- 更新检查地址改为本仓库。

提供 ARM64 精简版和四架构通用版，按设备选择安装。

安装提示：此前仓库未配置固定签名密钥，旧发行版使用临时 CI 签名。本版开始固定签名；若系统提示签名不一致，请先备份应用配置，再卸载旧模块后安装。不要卸载雀魂游戏。后续使用本仓库该固定签名的版本可覆盖升级。
