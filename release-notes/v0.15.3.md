# v0.15.3 · Hook 菜单焕新与对手昵称

- 按新版设计重做游戏内 Hook 菜单与收起状态栏：窄幅紫色半透明渐变面板、金色分段标签、紧凑设置行和状态信息。保留原悬浮球。
- 修正菜单视口与内容高度不一致导致底部被裁切、无法滚动查看的问题；对手昵称编辑区可展开查看。
- Hook 菜单和系统悬浮窗新增共用的对手昵称设置：正常、预设昵称、自定义。预设从左到右为「领头的羊」「镇山的虎」「远见的鹰」，三麻使用两个对手槽位。
- 切换昵称模式或保存自定义名称后，在游戏本地刷新当前牌桌座位显示；切回正常可恢复原名。
- 区服前缀继续由原有「显示服务器信息」开关独立控制，改名保留对应的 JP、CN、EN 等标识，不更改其他玩家看到的名称。

本地 ARM64 构建及布局、手势、文案、Rust 协议和 Lua 刷新测试已通过；不同设备上的实际视觉与触摸表现仍需实机反馈。

覆盖安装后请完全重启雀魂，以加载新版 Hook 与 Lua 资源。
