# v0.14.17

- 新增自己头像上方的暗色半透明信息窗，固定位置、点击穿透、不可拖动。
- 未听牌时最多显示三张推荐切牌及决策概率；听牌后显示各和牌张的番数、符数及荣和、自摸、立直后的基础点数。
- 游戏内绘制菜单与系统悬浮窗新增统一的“推荐与番点面板”开关，设置持久保存，不影响猫头提示和自动操作。
- 修复推荐概率字段读取错误导致 NaN 的问题，并按截图校准面板位置；放大文字，将右边框收至标题右侧少量留白。
- 三麻计分接入实际拔北数量。番点估算不含里宝、一发、本场、供托及未知和牌赤五加番，振听另行提示。
- 猫头提示增加渐变、高光和底沿厚度；猫头上移轻贴提示框上沿，增加顶部空间避免裁剪和遮挡数字。

本地通过 Kotlin 与 Android 测试源码编译、35 项 JVM 回归及 29 项计分相关源码测试；正式发布由 CI 继续完成全 ABI 构建及 Android 仪器测试。实局中的视觉贴合仍以实际设备为准。
