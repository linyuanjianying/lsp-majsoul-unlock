# v0.15.1 · 界面焕新与交互修复

- 管理应用四页统一暖米色背景、白色圆角卡片与深绿操作样式；加强概览文字对比度，移除日志条目左侧色条。
- 助手页重新分组：无人值守与自动续打独立卡片，操作延迟改为双端范围滑块，长说明与模型选项可展开查看。
- 系统悬浮窗和 Hook 菜单采用深蓝金橙主题，精简菜单结构与分组高度，改善功能开关显示空间。
- 修复 Hook 帮助图标空指针导致游戏闪退、帮助图标布局权重错误导致自动续打文字消失的问题。
- 修复悬浮面板不透明度计算错误；浮标支持状态胶囊、完整圆球与闲置半露贴边三态。
- Hook 功能仅点击右侧开关生效；支持列表上下滚动与左右切换页面，只有轻点面板外才自动收起，面板内空白不会触发收起。
- 调整贴顶把手为宽扁圆角样式，状态点与箭头横排；保留三语同步、跟随系统和牌上提示原样。

更新后请完全重启游戏。面板外点击仍传给游戏，不增加全屏透明拦截层。已有不透明度偏好保留，可在设置中调至100%。
